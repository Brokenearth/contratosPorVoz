# Preferencias de trabajo del propietario

## Cuenta de GitHub para publicar

- Si el usuario pide «sube los cambios a mi GitHub» sin indicar una cuenta, usar
  **Albertovillarraga1309**, a la que se refiere como **avillarraga**.
- Si el usuario dice «GitHub Brokenearth», «mi GitHub Brokenearth» o indica
  explícitamente **Brokenearth**, el destino es **Brokenearth**. Para este
  proyecto, el repositorio es `Brokenearth/contratosPorVoz`.
- Una cuenta o un repositorio indicados explícitamente tienen prioridad sobre
  la cuenta predeterminada y sobre el remoto `origin`.
- Comprobar la identidad conectada y los permisos del destino antes de subir
  cambios. Si no hay acceso de escritura, conservar el trabajo local y explicar
  el bloqueo. No publicar en otra cuenta como sustitución silenciosa; proponer
  un pull request o solicitar la conexión con acceso al destino.

## Commits

- Guardar el trabajo con commits locales aunque no sea posible subirlo a GitHub.
- Conservar la identidad Git del usuario. No añadir autorías, coautorías,
  firmas ni atribuciones de IA, asistentes o IDE a los commits.

Estas preferencias se aplican a las tareas que trabajen en este repositorio.
